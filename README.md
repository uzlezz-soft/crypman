# Crypman

Настольное JavaFX-приложение для работы с криптовалютным рынком и пользовательским портфелем. Клиент позволяет зарегистрироваться или войти, просматривать рынок, управлять балансом и активами, а также просматривать историю операций и статистику портфеля.

> Это клиентская часть курсовой работы, выполненной на втором семестре второго курса по предмету «Программирование сетевых приложений». Серверная часть находится в [другом репозитории](https://github.com/uzlezz-soft/crypman-server).

## Архитектура

- **Интерфейс (`gui`)** — экраны JavaFX описаны в FXML, оформление задаётся CSS, а обработчики пользовательских действий реализованы в контроллерах. Есть экраны входа, регистрации, рынка и портфеля.
- **Модели и состояние** — классы данных связывают ответы сервера с отображаемыми данными; `MarketState` хранит состояние списка криптовалют.
- **Сетевой слой (`network`)** — `ServerClient` устанавливает TCP-соединение с сервером. Клиент отправляет сериализованные объекты `Request` и получает `Response`; DTO запросов и ответов лежат в `network.schemas`.
- **Ресурсы** — FXML/CSS-файлы экранов, изображения и настройки подключения находятся в `src/main/resources`.

Клиент и сервер должны использовать совместимые форматы сообщений и протокол. По умолчанию адрес и порт задаются в `src/main/resources/server.properties` (`127.0.0.1:6969`).

## Что можно делать в приложении

После запуска клиент открывает экран входа. Пользователь может войти в существующую учётную запись или перейти к регистрации; перед отправкой формы регистрации приложение проверяет совпадение паролей. Дальнейшая работа с данными выполняется через сервер, а ответы с ошибкой показываются средствами интерфейса.

В пользовательском разделе доступны:

- просмотр баланса, состава портфеля и истории операций;
- пополнение баланса;
- покупка выбранных криптовалют с указанием сумм (клиент проверяет, хватает ли средств);
- продажа имеющихся активов;
- просмотр графика цены и статистики риска/доходности за выбранный период;
- расчёт статистики и подбор распределения покупки: под целевую доходность или с минимизацией риска;
- обновление данных, выход из учётной записи и экспорт истории портфеля в файл.

Для пользователей с административными правами предусмотрен отдельный экран управления рынком и системой. В нём можно просматривать и изменять сведения о криптовалютах и ценах, добавлять записи о ценах вручную или загружать их из CSV, просматривать пользователей и их историю, замораживать/размораживать учётные записи, а также просматривать и экспортировать системные журналы. Набор доступных действий определяется правами, полученными от сервера.

Взаимодействие устроено по схеме «действие в интерфейсе → запрос серверу → обработка ответа и обновление экрана». Клиент отправляет запросы по именованным маршрутам (например, `user/login`, `portfolio/buy`, `market/stats`) через TCP-соединение и получает соответствующий объект ответа. Поэтому для работы приложения нужен запущенный сервер, реализующий совместимый протокол.

## Технологии

- Java 17
- JavaFX 17 (Controls, FXML и другие модули)
- Maven
- Lombok

## Запуск

Необходимы JDK 17 и доступный экземпляр совместимого серверного приложения. Из корня проекта запустите:

```bash
./mvnw clean javafx:run
```

В Windows:

```powershell
.\mvnw.cmd clean javafx:run
```

Перед запуском при необходимости измените `SERVER_ADDRESS` и `SERVER_PORT` в `src/main/resources/server.properties`, чтобы они соответствовали адресу и порту сервера.
